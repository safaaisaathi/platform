# User App PRD

**This is a pointer.** The authoritative copy lives in the user app's own repo.

👉 **https://github.com/safaaisaathi/userapp/blob/main/docs/PRD-1-user-app.md**

**Do not edit this file.** Edit the canonical copy, then bump the `pin` and the `sourceHash` here.

## The contract surface

**The user app touches seven collections.** Everything else is off limits to it.

| Collection | Read | Write | The scope |
|---|---|---|---|
| `wards` | ✅ | ❌ | All of them. The citizen resolves their own ward |
| `routes` | ✅ | ❌ | All of them. The `wardIds` order is the ETA order |
| `vans` | ✅ | ❌ | **Only its own route.** `where('routeId', isEqualTo: ward.routeId).where('status', isEqualTo: 'on_shift')` |
| `trips` | ✅ | ❌ | **Only its own route**, for the "collected today" display. Scoped by the `routeId` claim |
| `complaints` | ✅ own | ✅ create | Scoped by the `deviceId` claim |
| `ratings` | ✅ own | ✅ create | Scoped by the `deviceId` claim |
| `notices` | ✅ | ❌ | The ward's notices |

## The two calls it makes

| When | What |
|---|---|
| Launch | `bootstrapUserSession({ deviceId, wardId })` → a custom token with `deviceId` and `routeId` → `signInWithCustomToken` |
| The ward changes | The same call again, to get a fresh `routeId` |

## The two indexes it needs, which do not exist yet

| Query | Index |
|---|---|
| The live vans on the route | `vans(routeId, status)` |
| The complaints of a ward | `complaints(wardId, createdAt DESC)` |

**Neither exists.** Without them the queries are collection scans. Check `../03-rules/firestore.indexes.json`.

## The three things this app must not do

| Must not | Why |
|---|---|
| Load all the vans | PRD section 0.6 rule 3 is a performance law, not a preference |
| Poll for the van's location | The push comes because the server decided. Polling scales with the citizens instead of the vans |
| Send the `deviceId` as a query parameter | It must be a claim. A parameter is forgeable |
